# Minha Pokédex

## API utilizada
PokéAPI — API pública e gratuita de informações sobre Pokémon.

Documentação: https://pokeapi.co/docs/v2

## Endpoint utilizado
https://pokeapi.co/api/v2/pokemon/{nome}

Exemplo:
https://pokeapi.co/api/v2/pokemon/pikachu

## Sobre o projeto
A aplicação permite pesquisar Pokémon pelo nome e visualizar:

- Nome;
- Imagem;
- Número na Pokédex;
- Tipo;
- Altura;
- Peso.

A página também apresenta mensagens de carregamento e tratamento de erros.

## Como executar
1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo index.html com a extensão Live Server.
3. Digite o nome de um Pokémon no campo de pesquisa.
4. Clique em Buscar.
